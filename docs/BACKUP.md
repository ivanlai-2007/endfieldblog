# 架構備份範圍

基準：6.3.3；整理日期：2026-10-24（Asia/Taipei）。

## 包含

- 原生前台、單人管理後台、Vercel API、內容驗證與私人媒體存取。
- 網址分享頁、批次整理、圖片檢視、垃圾桶與永久清除、統計、主題及動畫。
- 建置原始碼與目前產物、鎖定依賴清單、空的初始內容、通用設定產生器。
- 字體與授權、SVG／CSS 等高線素材、第三方授權文件。
- 合成資料測試、GitHub CI、README及完整操作文件。

## 排除或匿名化

- 正式照片、原始圖、網頁圖、縮圖、EXIF、文章、草稿、友鏈、個人介紹及社群帳號。
- 正式 Blob 的 CMS、歷史版本、統計、登入限制、永久清除計畫及認證狀態。
- 密碼、密碼雜湊、Session secret、Blob token、cookie及其他登入檔案。
- `.env.local` 等實際設定、`.local/`、`.vercel/`、原 Git 歷史、node_modules、日誌及交付截圖。
- 原有正式網域、Vercel帳號／專案／儲存庫識別與歷史部署紀錄。
- 舊的修復、清理、搬移及正式站測試腳本；只留下通用 build、dev、setup。
- 原本隨附的三張範例攝影圖片；EXIF 測試改用記憶體合成 JPEG/metadata。

原站檔案與遠端內容都沒有因為製作此備份而修改。新的匿名設定只存在這份副本。

## 如何還原程式

將這份程式部署到新環境，依 DEPLOYMENT.md 設定新 Blob 及認證，即可得到沒有個人資料的網站骨架。

若要恢復原站內容，需要管理者另外提供私人 CMS 備份及對應媒體，並保留原始媒體key／路徑。GitHub 包不提供這些資料，也無法單獨重建既有照片或文章。後台 JSON 匯入會驗證內容並保存新修訂；不能只把檔案放進 `public/`。

## 上傳時

請上傳此解壓專案，而非原工作目錄或整個 outputs 目錄。若後續在此副本開發，`.gitignore` 已排除本機環境、登入產物、匯出資料和依賴；提交前仍應檢視 `git diff --cached`。

隱私檢查結果及測試範圍見 VERIFICATION.md；壓縮檔旁提供 SHA-256 校驗碼。
