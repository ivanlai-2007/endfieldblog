# 內容管理

本備份啟動時沒有照片、文章或友鏈。正式內容儲存在私人 Blob，與原始碼分開保存。

## 照片

在 `/admin` 的照片頁選取 JPEG、PNG、WebP 或 AVIF（原始檔小於60MB）。瀏覽器先讀六欄 EXIF，再產生壓縮網頁圖及縮圖；原圖由自己保管。上傳後是草稿，補齊標題、描述、分類與署名，再發佈。

排序中的第一張公開作品是首頁精選。單張↑↓、拖曳與群組移至最前／最後都會更改排序。搜尋後可全選結果，批次修改分類、署名與狀態；空白欄位代表不修改。尚有未保存的單張編輯時，先保存或放棄再批次操作。

EXIF 無法讀取時保持空白，也可在後台手動填入。照片獨立網址為 `/photos/:id`，標題修改不影響網址。

## 垃圾桶

刪除照片先移到垃圾桶，前台會隱藏。還原後為草稿，需重新發佈。

永久刪除需再次確認，會移除紀錄並清除未與其他照片共用的網頁圖／縮圖。文章仍引用圖片時須先移除引用；草稿和封存文章也計入。清除中斷時在原項目重試，不能先還原正在清除的照片。永久刪除後，舊JSON備份也不會恢復已清除圖檔。

## 博客

新增文章並設定標題、摘要、分類、日期及 Markdown。先保存草稿及預覽，再發佈；目前不支援未來日期的排程發佈。內文可插入本站已發佈照片。Markdown 會清理腳本、危險網址及外部圖片。

正式文章網址為 `/notes/:id`，分享預覽優先使用內文第一張本站圖片，否則採精選照片。社群平台可能快取舊預覽。

## 友鏈

填寫名稱、HTTPS 網址、簡介及標籤，調整順序與狀態。隱藏或封存內容不在公開資料中。

## 網站設定與個人頁

後台網站設定可修改作者名稱、網站名稱、頂部標題、首頁主標題、描述及介紹文字；個人介紹保留換行。字體、頁面骨架、興趣細項與社群入口位於 `public/index.html` / `public/style.css`。

此副本的社群列已隱藏，三個網址皆為 `example.com` 範本。使用自己的平台網址及帳號替換後，移除 `.profile-social` 的 `hidden`。請同步填妥顯示文字及無障礙標籤。個人資料可透過私人內容備份另行還原，請勿提交到此架構儲存庫。

內建色彩預設來自 `data/seed.json` 的 `looks`，不是管理內容；修改後需建置部署。既有內容在下一次通過管理保存時，會採用目前程式的預設設定。

## 日常備份

後台「網站設定 → 內容備份」可匯出 JSON，包含設定、草稿與照片資訊，但不包含圖片檔案。請放在私人位置。私人 Blob 的 `media/`、`history/`、CMS、認證狀態與統計若需完整災難還原，應另外使用私人儲存備份流程，不能只備份 GitHub 原始碼。
